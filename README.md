# Toy Store Tycoon v0.8.2 — Premium Shelf + Store Presentation

This build supersedes v0.8.1 and keeps the existing Warehouse + Distribution Network, Multi-Store Expansion, Retail War, Franchise Universe, Collector Economy and premium product package art intact.

## Focus of v0.8.2
The priority of this release is making the store itself feel more premium, aspirational and toy-retail driven. v0.8.1 upgraded the individual product packaging; v0.8.2 upgrades how those products are presented across the store floor and supporting shopping surfaces.

## Major changes
- **Store world presentation rebuilt** with stronger shelf bays, a central featured launch island, clearer launch banner treatment and more premium in-store visual layering.
- **Shelf layouts improved** from a flatter presentation into more distinct left/right merchandising bays with better product framing and shelf base treatment.
- **Store fixtures and destination zones added** including branded mini-destinations and a clearer “launch island” / “feature wall” feel.
- **Featured launch banners improved** so the current top product reads like a true toy-retail promotional moment.
- **Product-card framing upgraded** on market and store showcase surfaces with stronger shadows, premium card containers and cleaner package staging.
- **Franchise destination section added** on the Store screen so key brands feel like discoverable in-store worlds rather than just a list of SKUs.
- **4 store backdrop SVGs rebuilt** (starter / neighbourhood / premium / flagship) to better support the improved in-store composition.
- Existing v0.8.1 saves migrate automatically into **`toyStoreTycoon.v0.8.2`**.
- Updated service-worker cache key so GitHub Pages/PWA installs refresh the new store presentation cleanly.
